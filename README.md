# Projetos em Destaque

## CatBills

Ecossistema de controle financeiro e orçamento doméstico desenvolvido com back-end em C# (.NET 8), persistência física em SQLite via EF Core e interface dinâmica Single Page Application (SPA) com HTML5 e Tailwind CSS.

O projeto implementa comunicação assíncrona com o servidor via Fetch API em tempo real, injeção de dependência nativa no back-end e isolamento de entidades através de DTOs de exibição de dados.

## CineMatch

Diário de cinema e auto-gestão de filmes desenvolvido com back-end em Python (Flask), banco relacional PostgreSQL via Supabase Cloud e interface reativa com Fetch API e Bootstrap 5.

O projeto implementa consumo assíncrono da API do TMDB em tempo real, rotas RESTful no back-end e tratamento de buscas com normalização de acentos no servidor.
